# What is deliberately not built — and the answer for the sales call

Spec 18.7, filed 2026-09-15. Stated so each is a decision rather than a gap
found in an audit. Each will be asked about. The answer is that it is not
built and why — never an implied roadmap.

| asked for | not built because | the answer in one sentence |
|---|---|---|
| Native mobile apps | D1: one web surface, installable PWA; parents install nothing and create no account. Two clients is two places a bug about a minor can live. | "Sporv is a website that installs like an app. Your families get a link, not an app store." |
| Website builder (spec 14.6) | The club already has a website; Sporv reads it (`club-site-extract`) and publishes a registration page, not a site. | "We put your registration and schedule on a page you can link from the site you already have." |
| Photo and video sharing, team chat, parent community (13.8) | Media of minors and an unmoderated chat are the two features that end a youth-sports company. Consent-gated media exists for the coach's own records only. | "Not in Sporv on purpose. Use the group chat you already have; Sporv sends the links into it." |
| League bracket and tournament management | A different buyer (the league), a different season, a different product. | "We run the club. Your league's brackets stay where they are; we import the schedule they publish." |
| Official and referee assignment | Same: a league-side workflow. | Same. |
| Merchandise, uniforms, fundraising | Money paths outside dues need their own reconciliation; every extra path is a place the ledger can drift. | "Dues, registration and payment plans. Merch stays with your vendor." |
| Sanctioning-body API integration in v1 (16.6) | No sanctioning body exposes a stable API a small vendor can rely on; the field on the lead record captures which body a club answers to, and the certification reports cover the paperwork. | "We record which body you answer to and keep your certifications current; we do not file with them for you yet." |

Each fails the cut rule (does it remove minutes from a director's week this
season?) or exceeds the launch window. Revisit only when a paying org asks
twice and the ask survives the cut rule.
